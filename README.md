# 원우ENG MES POP 프로토타입

원우ENG 제조 현장의 키오스크 작업자를 위한 HTML 기반 MES POP 프론트엔드 프로토타입입니다.

첫 화면에서 공정을 선택한 뒤 최종검사 또는 절단 공정 POP로 이동할 수 있습니다. 서버나 외부 API 없이 브라우저에서 실행되며, 절단 공정 데이터는 `localStorage`에 저장됩니다.

최종검사와 절단 POP의 `작업자 선택` 버튼에서 작업자 이름을 변경할 수 있으며, 선택한 이름은 모든 화면과 이후 생성되는 절단 작업실적에 반영됩니다.

## 주요 화면

### 공정 선택

- 최종검사 공정과 절단 공정 선택
- 오늘 날짜와 작업자 표시
- 원우ENG 공식 CI 적용

### 최종검사 공정

1. 작업지시 선택
2. 작업시작
3. 디지털저울 무게 자동 I/F 시뮬레이션
4. 측정 무게 확정
5. 작업종료

### 절단 공정

1. 자재 입고 등록
2. 자재 재고에서 작업할 자재 단일 선택
3. 자재 절단 및 절단 완료
4. 잔재 처리 또는 잔재 미처리 선택
5. 잔재 크기 검증 및 재고 등록
6. 잔재 미처리 절단실적 조회

절단 공정에서는 자재 재고, 잔재 재고, 작업실적 탭을 제공합니다. 자재 재고는 원장 재고와 잔재 재고를 합친 개념입니다. 잔재 미처리를 선택하면 확인 팝업이 표시되며, 절단 완료를 확정한 경우에만 작업실적이 생성됩니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 공정 선택 화면 |
| `process-select.css` | 공정 선택 화면 스타일 |
| `process-select.js` | 날짜와 현재 시각 표시 |
| `operator.css` | 공통 작업자 선택 버튼과 팝업 스타일 |
| `operator.js` | 작업자 이름 입력, 저장과 화면 반영 |
| `final-inspection.html` | 최종검사 무게 I/F POP |
| `styles.css` | 최종검사 화면 스타일 |
| `app.js` | 최종검사 화면 동작 |
| `cutting.html` | 절단·잔재 관리 POP |
| `cutting.css` | 절단 화면 스타일 |
| `cutting.js` | 입고, 절단, 잔재, 작업실적 로직 |
| `assets/wonwoo-ci.jpg` | 원우ENG 공식 CI 이미지 |
| `docs/design/` | 화면 설계 기준 시안 |

## 실행 방법

파일을 내려받은 뒤 `index.html`을 브라우저에서 직접 열 수 있습니다.

로컬 웹 서버로 실행하려면 프로젝트 폴더에서 다음 명령을 사용합니다.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 다음 주소로 접속합니다.

```text
http://127.0.0.1:8000/
```

## 데이터 저장

- 절단 자재 재고, 잔재 재고와 작업실적은 브라우저 `localStorage`에 저장됩니다.
- 선택한 작업자 이름도 브라우저에 저장되어 공정 이동과 새로고침 후 유지됩니다.
- 브라우저 새로고침 후에도 저장된 데이터가 유지됩니다.
- `데이터 초기화`를 누르면 최초 더미 자재 재고 10건과 잔재 재고 3건으로 복원됩니다.
- 실제 MES 서버, 데이터베이스, 설비 통신은 포함하지 않은 프론트엔드 프로토타입입니다.

## CI 출처

공정 선택 화면의 CI는 [원우ENG 공식 웹사이트](http://wonwooeng.com)에서 사용하는 공식 로고 이미지를 프로젝트 내부에 저장해 사용합니다.
